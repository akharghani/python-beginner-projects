# Python Beginner Projects

Two small programs I wrote while learning Python in Introduction to Python course in Fall 2025. 
They're simple, but they were my first projects built from scratch: planning with pseudocode, splitting code into functions, and checking user input.

| Project | What it does |
|---|---|
| [Text Stats Analyzer](text-stats-analyzer/) | Counts words and letters in a sentence and finds the longest and most common word |
| [Fuel Calculator](fuel-calculator/) | Asks for trip distance and fuel stops, then works out L/100 km and total fuel cost |

Both need only Python 3, with no extra packages. See each folder's README for how to run it.
